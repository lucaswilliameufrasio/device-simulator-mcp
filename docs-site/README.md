# Device Simulator MCP Site

Static Astro landing page for Device Simulator MCP. It uses Tailwind CSS v4
through the official Astro Vite integration.

## Development

```bash
pnpm install --frozen-lockfile
pnpm dev
```

## Production Build

```bash
pnpm build
pnpm preview
```

The generated site is written to `dist/`. No server runtime or secrets are
required.
